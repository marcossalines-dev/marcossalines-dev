### 💻 Projetos em destaque

#### [Sistema de Cadastro de Pessoas](https://github.com/marcossalines-dev/sistema-cadastro-pessoa)

API REST desenvolvida com Java e Spring Boot, integrada ao MySQL.

**Tecnologias utilizadas:**
- Java 25 e Spring Boot
- Spring Web e Spring Data JPA
- MySQL e Maven
- Jakarta Validation
- JUnit 5 e Mockito

**Funcionalidades implementadas:**
- Cadastro, consulta, atualização e exclusão de pessoas.
- Validação dos dados recebidos.
- Tratamento global de exceções.
- Testes automatizados da camada de serviço em desenvolvimento.

O projeto faz parte da minha evolução prática em Backend e está sendo desenvolvido gradualmente, com atenção à organização do código e à compreensão das responsabilidades de cada camada.
